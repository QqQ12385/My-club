01消息怎么进来：平台 → 统一入口

钉钉侧用企业内部应用 + Stream 长连接实时接收：群里 @机器人 的文字、文件、图片都会实时推送到本平台，无需公网回调。微信侧因个人号无开放接口，用 Power Automate 桌面自动化采集后经纯文本接口入库。

钉钉：真实双向

Stream 订阅机器人消息主题，文字/文件/图片三类消息全支持；文件走官方下载接口拉取字节并留档。

微信：RPA 半自动

个人号没有 API，用桌面自动化复制消息 → 纯文本接口入库；发送侧为模拟回执。这是平台限制下的务实方案。

02会话与回复：同一人一个会话

消息列表按联系人合并：同一人（平台+发送人）只占一行，显示最新一条和未读数；点进去是连续气泡，和微信一样。回复时消息经发送路由真实发回钉钉群并 @对方，不是只在网页里假装。

回复支持主备通道降级：主通道（API）失败自动切备用（Webhook / RPA），仍失败则渲染失败气泡并给出重试 / 切换通道重试按钮。

03文件互传：双向都留档

方向链路结果
网页 → 钉钉媒体上传 API 换 mediaId → sampleFile 发到群群内真实收到文件，网页气泡可点击下载
钉钉 → 网页机器人收到文件消息 → messageFiles/download 换URL → 拉取字节留档网页实时出现文件气泡，点击可下载打开
留档设计：所有收发的文件都存本地磁盘并建 files 表索引，删除消息时级联清理磁盘文件，不留孤儿文件。

04消息撤回：两个方向的同步

网页里撤回自己的消息

自己发的气泡带「撤回」按钮，撤回后变灰显示「已撤回一条消息」——记录保留痕迹，与微信语义一致。别人的消息只有删除，不能替对方撤回。

钉钉里撤回 → 网页自动同步

Stream 订阅了撤回事件：对方在钉钉撤回后，网页对应消息自动变灰「对方在钉钉撤回了一条消息」，经 WebSocket 实时推送。

05好友清单：自动聚合 + 手动添加

  • 自动聚合：收到过消息的平台联系人自动出现在清单，显示平台、会话、最后消息、未读数。
  • 手动添加好友：消息页「+ 添加好友」填平台和名字，持久化入库；与已有联系人自动合并，不会出现两个同名人。
  • 主动发消息：每个联系人卡片有「发消息」，弹出输入框即走真实发送路由并 @对方。
  • 删除好友：好友卡片支持移除。

    07钉钉扫码登录：OAuth 授权

  • 登录页点「钉钉扫码登录」，跳转钉钉授权页。
  • 手机钉钉扫码确认，授权码回调到本平台。
  • 后端用授权码换取用户 unionId 与昵称，首次自动注册本地账号并绑定。
  • 以后再扫直接登录同一账号，无需密码。

    • 扫码登录与消息收发共用同一套企业应用凭据，是两个独立能力：收发靠 Stream 长连接，登录靠 OAuth 授权码模式。

    08记录管理与导出

    删除单条记录（气泡级）、删除整个会话（按联系人）、清空全部记录，均真删数据库并级联清理文件与流转时间线。顶栏「导出记录」一键导出 CSV（UTF-8 BOM），Excel 直接打开不乱码——导出为纯真实数据，无任何演示种子。

    09AI 能力：分类 / 建议 / 自动回复

    DeepSeek 对新消息智能分类（待办自动入列）、基于上下文生成回复建议、跨平台聚合每日摘要；会话页可开启 AI 自动回复开关，新消息进来自动生成并发送。无 Key 时自动降级规则引擎，闭环不中断。

    10应用连接器：WorkBuddy 式管理

    「应用连接」页展示每个平台的主备通道、连接状态、最近同步与成功率，支持连接 / 断开 / 连通性测试，风格对标 WorkBuddy 的连接器管理。
